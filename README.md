# whats_cooking
Women in Data - Datathon 2026, Food Systems Data Analysis Challenge

Analysis will flow in a sequential storyline:
## Part 1: Livestock Growth (outputs: livestock quantity, % increase, density metrics by Country)
### Part 1 will identify countries with the largest increase in livestock production in the last 10 years

## Part 2: Manure & Emissions (outputs: manure and emissions quantity from chickens, cattle, and pigs Country)
### Part 2 will identify the amount of manure and emissions from key livestock per Country

## Part 3: Waste-to-Energy Solution (outputs: biogas yield potentials & target sites)
### Part 3 will identify the amount of households biogas could generate as a renewable energy source by Country and livestock type

All tables will need to include Area Code (M49) as the primary key. Each table will need to have a common name for each type of livestock animal.
For example, the Crops and Livestock products table has Stocks as an element with the Item as "Cattle, dairy" and "Cattle, non-dairy" values. We will need to convert this to "Cattle".
